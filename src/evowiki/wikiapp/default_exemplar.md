# 讲法样板：从熟悉的做法一步步走到新办法

这是一页示范“怎么讲”的样板，主题故意选得很小（Python 里用字典查找，而不是在列表里一个个翻）。学它的讲法：先后顺序、每一步做什么、怎样不让学习者卡在没解释过的词上。不要照抄它的标题、例子或内容。方括号里的「讲法」是给你看的注释，写页面时不要出现。

## 先说结论

字典查找的快，不是因为电脑变快了，而是因为它不用一个个翻：知道“东西放在哪一格”，直接走过去拿。

> 【讲法】开头一两句人话说清“这是什么、解决什么问题”，后面再慢慢建立证据。

## 1. 你现在的做法：在列表里一个个找

假设有一份名单，要找“小李”的电话。你已经会的写法是把名单放进列表，从头往后看：

```python
people = [("小王", "138-0001"), ("小李", "138-0002"), ("小张", "138-0003")]

for name, phone in people:
    if name == "小李":
        print(phone)
```

预期输出：`138-0002`。从头开始，看到“小王”不对，再看“小李”，对了。

> 【讲法】从他已经会的普通代码出发，不是从定义出发。代码小到一眼看完，并写出预期输出。

## 2. 问题什么时候真的出现

三个人时没有问题。把名单换成一百万人，找最后一个人，就要一个一个比较一百万次。可以让计算机自己数一数：

```python
people = [(f"人{i}", i) for i in range(1_000_000)]
count = 0
for name, phone in people:
    count += 1
    if name == "人999999":
        break
print(count)
```

预期输出：`1000000`。找得越靠后，比较的次数越多，次数和名单长度同步增长。

> 【讲法】用一个能观察到的输出（比较了多少次）让问题真实出现，而不是只说“慢”。

## 3. 我们想要的新办法（先不写任何新语法）

我们希望：看到名字，不用一个个比，直接知道电话放在“哪一格”。就像小区信箱——按门牌号直接走到那一格，不用把每个信箱都打开看一遍。

这一步要的只是一个动作：**名字 → 位置 → 取出**。

> 【讲法】先用人话说新方法改变了什么过程，还不给正式名称。

## 4. 把这句话翻译成 Python

现在才出现新写法，一次只加一个：

- `{}`：一个“按名字放东西”的容器。
- `{"小李": "138-0002"}`：左边是名字（取东西的凭据），右边是放的东西，冒号表示“这个名字对应这个值”。
- `book["小李"]`：用名字直接取值。

```python
book = {"小王": "138-0001", "小李": "138-0002", "小张": "138-0003"}
print(book["小李"])
```

预期输出：`138-0002`。这一次没有 `for`：没有从头往后看。

> 【讲法】每个新符号第一次出现前先讲清它是什么、输入什么、产生什么；一行里有几个新东西就先拆开。例子紧跟其后，结果写出来。

## 5. 逐步追踪：它是怎么直接走到那一格的

用同一份数据，单步看 `book["小李"]`：

1. 拿到名字 `"小李"`。
2. 用一个固定的规则把名字算成一个数，这个数决定放在哪一格（这一步叫哈希，下一节再正式讲）。
3. 直接去那一格，取出 `"138-0002"`。

对比第 2 节：列表要比较一百万次；字典不管有多少人，都是“算一下位置，走过去”，次数几乎不变。

> 【讲法】逐步追踪时一步只变一处，把输入、变化的位置和输出连起来；再回到第 2 节的对照证据。

## 6. 现在再给它们正式的名字

- **字典（dict）**：按“键”存取“值”的容器。人话说：按名字放、按名字取。例子里的位置：`book` 和它的 `"小李"`。别混淆：它不是有顺序的名单，查找靠键而不是靠位置编号。
- **键（key）和值（value）**：名字和电话。
- **哈希（hash）**：把键算成位置的那个规则。别混淆：它不是加密。

> 【讲法】正式术语放在直觉和例子之后，每个核心术语讲全：人话解释、正式定义、例子里的位置、别混淆。

## 7. 自己预测一次，再带走一条规则

把名单改成十个人再找最后一个，列表要比较几次？字典呢？先想，再运行。

可以带走的规则：**经常按名字找东西，就用字典；只是从头到尾走一遍，列表就够了。**

遇到新场景时问两个问题：我是在“按名字找”，还是在“逐个处理”？数据会不会变得很大？

> 【讲法】最后给可迁移的规则，让他能用自己的话复述、回答追问、预测一个新情况。
