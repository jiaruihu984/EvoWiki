# EvoUI：揭开、动效和计时

- `reveal`（先遮后揭）：`children` 先被一块条纹占位遮住。`mode`：
  - `"click"`（默认）：点一下全部显示，按钮文字是 `label`（默认「显示」）。用于「先自己想，再看答案 / 解释」。
  - `"steps"`：每点一次多显示一个子节点，按钮是「下一步 (k/N)」（写了 `label` 就用它代替「下一步」）。用于分步推导、
    分步提示：每个子节点是一步。
  - `"after"`：`after` 写一个练习节点（`quiz`、`flashcards`、`fill-blank`、`sentence` 或 `pager`）的 `id`，读者做完那个练习后才显示，占位上写 `label`
    （默认「完成上面的练习后显示」）。用于答完再给的解释、延伸、下一步建议。`after` 必须是这个块里存在的练习节点的 `id`，
    而且不能在这个 reveal 里面。
  - 全部显示后可以「再遮住」重来（click / steps）。被遮住的内容读者看不到，不要把读者必须先看的东西放进去。
- `animate`：子节点出现时淡入（`effect`："rise" 默认，带 4 像素上移；"fade" 只淡入）；放在 `if` 里，每次切换出来都会播放。
  只用来强调「新出现的结论」，不要整块都包。
- `transition`：`key` 是一个表达式（如 `"step"`、`"mode"`），它的值一变，里面的内容就旧的淡出、新的淡入，适合「换一页 /
  换一种情况」的读数或说明。连续变化的数（滑块拖动时）不要用 transition。
- 不用写也会有的动效：`if` 每次切换分支都会淡出旧的、淡入新的；plot / chart 的图形随 state 变化时会平滑移动到新位置
  （形状个数不变时），表格行重新排序时会滑到新位置。读者开了「减少动态效果」时这些都没有。
- `celebrate`：`when` 是表达式，从假变成真的那一刻撒一次彩纸（打开页面时已经为真不算；变回假之后可以再撒）。
  只用于真正的「完成」时刻，如「排序完成」「找到了最优解」。
- `timer`：`"countdown"` 倒计时（`seconds` 秒，必填），到 0 变绿显示「时间到」；`"stopwatch"` 秒表（不写 `seconds`）。读者
  可以开始 / 暂停 / 重置；`autostart: true` 出现时自动开始。`bind`（可选）是一个数字 state，每秒写入已经过去的整秒数，
  可以用它让文字或图随时间变化。计时进行中完成的练习，结果里会带上计时的用时。用于限时练习、估算自己要多久。
