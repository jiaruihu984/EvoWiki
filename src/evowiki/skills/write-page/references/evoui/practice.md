# EvoUI：练习卡、翻页和选择路线

- `fill-blank`（填空）：`sentence` 是一句纯文字，用三个下划线 `___` 标出唯一的空。`options` 是候选（2–8 个，`label` 是填进去
  的词或数，`why` 可选：选了它为什么对 / 错，错的要点出对应的误解），`correct` 是正确候选的序号，`why` 是这道题的解释。
  读者点一个候选，空里先出现它，接着变绿（对）或变红（错），所有候选变暗不能再选；答错时显示完整的正确句子、这个候选的 `why`
  和题目的 `why`，可以「再试一次」。用于一个关键词 / 数 / 符号的辨认：候选要是读者真会混淆的说法。
- `sentence`（拼句）：`sentence` 里有 1–8 个 `___`，`words` 是词库（至少和空一样多，最多 12 个，不能重复；可以多给几个干扰词），
  `answer` 按空的顺序写每个空的正确词序号（如 `[0, 2, 1]`）。读者按顺序点词填空，用过的词变暗并标上第几个，↶ 撤销最后一个；
  填满自动判分，只把填错的空标红，并显示完整的正确句子和 `why`；可以「再试一次」。用于公式的组成、步骤的顺序、句子的结构。
- 两种练习都可以写 `cell`（只能用这一页给出的格子）：每次作答都作为测验证据记进学习记录。进度按这一个节点记：改写块时不要
  改 `options` / `words` 的顺序。
- `pager`（练习翻页器）：`children` 每个是一页（一个节点，常见是一个 `fill-blank` / `sentence` / `quiz`，也可以是一个 `box`：
  一句引导 + 一个练习）。顶部「‹ n/N ›」翻页，底部「下一题」，最后一页是「完成」；按「完成」时记一次总结（里面所有练习答对
  几个），全对会撒彩纸。`gate: true` 时，这一页的练习都做完才能往后翻（没有练习的页随时可以翻）。用于一组 3–8 个小练习，
  比把它们排成一长列更专注。翻页器里不能再放翻页器。总结按每个练习最后一次的作答算（答错后「再试一次」答对也算对，所以重做后全对也会撒彩纸）；
  放在 reveal 遮罩里的练习也要做完才能翻页（读者得先揭开它），所以 `gate: true` 的页里不要把练习藏进 reveal。
- `route`（选择路线）：`prompt` 问读者接下来想怎么学，每个选项 `label`（短，几个字）、`desc`（可选，一句说明）、`value`（选项的
  值：短文字、数字或 true/false，互不相同）和 `next`。**`next` 是一句指令：宿主可能把它作为读者的下一轮消息发给模型**（如
  「请一步一步引导我解这道题，每步先问我」），要写成读者口吻的完整请求。选中的选项高亮，其他变暗；读者可以改选，每选一次都记
  一次。`bind`（可选）把选中的 `value` 写进一个 state（类型要和 state 一样），可以用 `if` 让块里的内容跟着变。读者没选之前哪个都不高亮（即使 state 的初始值等于某个选项的 `value`）。`preference`
  （可选）是偏好的名字，如 `"teaching_mode"`：写了它，读者的选择会作为这个偏好（读者喜欢的教学方式）记下来。用于「一步步引导 /
  直接看答案 / 考考我」这类教学方式的选择，或「先看图 / 先看公式」这类学习路线的分岔；不要用它出有对错的题（那是 quiz）。
