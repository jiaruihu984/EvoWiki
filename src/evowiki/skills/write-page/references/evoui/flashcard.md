# EvoUI：闪卡

- 用来记住成对的东西：术语 ↔ 意思、符号 ↔ 读法、问题 ↔ 一句话答案、公式 ↔ 用途。每张卡 `front`（正面：要回想的
  提示，越短越好）和 `back`（背面：答案，一两句话；可以用换行或「- 」开头的列表行）都是纯文字，最多 600 字。
- 读者点卡片（或按空格）翻面，自己判断：左滑 / ✗ / ← 是「没记住」，右滑 / ✓ / → 是「记住了」；可以撤销上一张、
  洗牌（只洗还没看的；`shuffle: false` 不显示洗牌按钮）。看完一轮显示记住几张、没记住几张，可以「重新开始」或
  「复习 N 张没记住的」；全部记住会撒彩纸，并出现「更多卡片」（告诉系统读者想要更多）。
- `hint`（可选）：一句提示，读者自己点开才看到（看了提示记住的，在学习记录里算弱一点的证据），只给方向。
- `cell`（可选）：这张卡对应的知识格子，**只能用这一页给出的格子**；读者每次「记住 / 没记住」会记进学习记录。
- 每一轮看完时才把这一轮每张卡最后的「记住 / 没记住」记进学习记录（中途撤销改过的以最后为准；没看完的一轮不记）。
- 进度按卡片在 `cards` 里的位置记：改写这个块时保持已有卡片的顺序，新卡加在最后，不要重排或从中间删卡。
- `title`（可选）：这叠卡的小标题（纯文字）。一叠 4–12 张最合适；不是成对记忆的内容（要推理、比较、计算的）
  用测验或自己拼的交互，不要用闪卡。
