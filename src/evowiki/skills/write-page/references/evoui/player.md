# EvoUI：播放器

- `player`：一个播放器，把数字 state `bind` 从 `min` 每隔 `interval_ms` 毫秒（默认 700）加一个 `step`，到 `max` 停下
  （`loop: true` 则回到 `min` 继续）。读者可以播放 / 暂停、上一步 / 下一步、回到开头、拖进度条、选 0.5× 1× 2× 速度。
  用于「一步一步看过程」：排序 / 搜索等算法的每一步（state 是步数，`derived` 里用 `iterate` 算出每一步的状态）、参数扫描
  （傅里叶项数、时间 t）。图里的形状会随步数平滑移动。`label` 写当前在做什么，如「第 {step} 步」。它和滑块一样算控件：
  检查时会把它设到 `min` 和 `max`，那段文字或图要真的变。
