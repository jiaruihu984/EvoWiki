# EvoUI：图表

- `"line"` 折线、`"area"` 面积（折线下面填色）、`"bar"` 柱状、`"scatter"` 散点、`"pie"` 饼图。
- `stack`（bool，bar / area）：多个系列叠起来（柱子叠成一根，面积一层叠一层），y 轴按叠起来的总数。用于「总量由几部分组成」。
- `curve`（line / area）：`"linear"`（默认，折线）、`"smooth"`（平滑曲线，不会冲过数据点）、`"step"`（阶梯：值保持到下一个点才跳，
  用于分段计费、离散状态）。
- `gradient`（bool，area）：面积从上到下渐渐变淡。
- `hover`（line / area / bar）：一个数字 state 的名字（初值写 -1）。读者把鼠标移到图上（或聚焦图后按 ← →）时，它等于最近那个
  数据点在 `data` 里的序号，离开时变回 -1。图上会显示竖线和提示框（这一点的 x 和每个系列的值）。用它让图外的大数字或说明
  跟着悬停的点变，如 `{"kind": "title", "text": "{h < 0 ? fmt(d[len(d) - 1].p, 2) : fmt(d[h].p, 2)}"}`（不悬停时显示最新值）。
- `visible_points`（line / area / bar，整数 ≥ 3）：数据点比它多时，一次只显示这么多个（开始时显示最后的几个），其余的在图里左右拖动、
  Shift + 滚轮或拖下面的「拖动查看更多」查看。用于很长的时间序列。
- `annotations`（line / area / bar，最多 8 个）：`{"x": 表达式, "label": 模板, "tone"}` 在这个 x 画一条竖的虚线（x 写 `data` 里
  某个点的 x 值；是数字且没有点的 x 等于它时，当作序号），`{"y": 表达式, "label", "tone"}` 画一条横的虚线（如目标线、平均值），
  标签在右端。用于标出关键时刻、阈值。
- `donut`（bool，pie）：环形图，中间显示合计；悬停扇区或图例时这块突出、中间显示它的名称和占比。
- 不悬停时，每条折线 / 面积的最后一个点有一个指示点。点图例可以隐藏 / 显示一个系列（至少留一个）。这些都不用写。
