# EvoUI：时间线和「深入一点」

- `timeline`：按先后顺序竖排的事件或阶段，左边一条线串起来。每项 `title`（必填，短）、`when`（可选：年份、日期或阶段名，
  如「1905」「第一阶段」；写了就显示在标题上方，没写的项按顺序编号 1、2、3……）、`text`（可选，一两句说明，可以换行）、
  `tone`（可选，圆点的颜色：关键的一项用 `"accent"`，出错 / 转折可以用 `"warning"` / `"danger"`）。都是纯文字。
  用于顺序本身就是要记住的东西：历史事件、一个领域的发展阶段、一个过程的几个环节。不是先后关系的并列要点用文字列表，
  要读者一步一步想的推导用 `reveal` steps。
- `deep-dive`：`children` 折叠在一行「▸ 深入一点」（`label` 可以换成具体的，如「深入一点：为什么是 1/2」）下面，读者点开才看到，
  点开时有淡入。里面可以放任何节点（文字、公式、表格、图、时间线）。用于正文不需要、但有人会想知道的部分：推导或证明、例外和
  边界情况、来龙去脉、更严格的说法。读者可能永远不点开，所以读懂正文必须的内容、要做的练习都不要放进去。
- 两个都不记进学习记录，也没有进度。
