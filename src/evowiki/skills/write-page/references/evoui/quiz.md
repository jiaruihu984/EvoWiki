# EvoUI：测验和诊断

- 每题 `options` 2–8 个，`correct` 是正确选项的序号（从 0 开始），`why` 是答完后显示的解释。
- `type`（可选）：`"single"`（默认，单选）、`"multi"`（多选：`correct` 写成序号列表，如 `[0, 2]`，至少一个、
  不重复；要全部选对才算对）、`"tf"`（判断题：正好 2 个选项，如 `["对", "错"]`，`correct` 仍是序号）。
- `feedback`（可选）：每个选项一句解释，个数和 `options` 一样，顺序对应。判分后显示在读者选的选项和正确选项
  下面——写清「为什么这个错 / 为什么这个对」，错的选项要点出它对应的误解。
- `hint`（可选）：一句提示，读者自己点开才看到（看了提示的答案在学习记录里算弱一点的证据）。提示只给方向，
  不直接说答案。
- `layout`：`"list"`（默认）所有题一起显示，最后按「检查答案」；`"paged"` 一页一题的练习卡：单选 / 判断点一下
  就判分，多选选好后按「提交答案」，判分后锁定并显示解释，答完才能翻下一页；最后是结果页（得分、每题对错、
  正确答案和解释），可以「重新开始」「只做错题」或「再来一套」，全对会撒彩纸。题目多（4 题以上）、想让读者
  一题一题想清楚时用 `"paged"`；几道题互相对照着看时用 `"list"`。
- `title`（可选）：测验的小标题（纯文字），如「检查一下：概率」。
- 诊断测验：给 `cases`（1–6 种情况，`id` 用小写字母 / 数字 / `-` / `_`，`advice` 是这种情况答错时该回看什么），
  每道题用 `case` 标它属于哪种情况。答完显示总分和每种情况答对几道。
- `cell`（可选）：这道题考的知识格子 id，**只能用这一页给出的格子**（如 `c1.interpret`）。写了 `cell` 的题，
  读者的答案会作为测验证据记进学习记录，答错时还能选「粗心 / 学会了 / 看不懂」。
