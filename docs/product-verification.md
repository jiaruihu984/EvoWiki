# 支持范围

EvoWiki 0.1.0 的一键安装面向 Windows 11 x64、Obsidian 桌面版 1.15.0 或更新版本，以及个人本地使用。默认使用 CPU 向量检索，不要求 NVIDIA 显卡。需要自己的模型 API 密钥。

安装、更新、备份、恢复和卸载步骤见 [README](../README.md)。软件、数据库、笔记和配置应由同一安装实例管理；接入已有笔记库时请先备份。

## 功能范围

- 提出目标、确认学习背景和路径、生成讲解页面。
- 在 Obsidian 阅读 Markdown、操作互动示例和回答检查题。
- 保存个人笔记、提出反馈并确认页面修改。
- 继续学习和主动复习，保留本地学习记录。
- 查看模型用量、调整预算，以及选择是否启用后台自动化。

RSI 需要真实反馈、可比较的评测基线及用户授权。默认不自动修改代码；缺少证据或门控未通过时不会作为已验证改进上线。长期学习收益取决于实际使用，不能由安装检查代替。

## 平台与部署限制

当前不承诺 macOS/Linux 与 Windows 相同的一键安装体验，不面向多人共享或公网部署。应用预算为软限制，不能替代模型供应商账户限额。外发内容与数据位置见 [README](../README.md)。
